# MVP: договоры из реквизитов

Этот MVP реализует шаги:
1. загрузка файла с реквизитами,
2. извлечение реквизитов (regex/OCR-like по тексту),
3. ручная правка полей,
4. генерация DOCX,
5. базовая валидация реквизитов,
6. шаблоны по типам договоров (`supply`, `service`, `sale`).

## Запуск
```bash
python mvp_web_app.py
```

Откройте: `http://localhost:8080`

## Что проверяется
- обязательные поля;
- ИНН (10/12 цифр);
- БИК (9 цифр);
- р/с и к/с (20 цифр);
- `client.kpp` обязателен для `client.type=ooo`.

## Ограничения MVP
- Для фото/PDF/DOCX без OCR-библиотек извлечение может быть частичным;
- Если автопарсинг не распознал поля, заполните вручную в форме.
